# Security Policy

## Supported version

Security fixes target the current `main` branch and latest release.

## Reporting

Please report a suspected vulnerability privately through GitHub's security reporting facilities when available rather than opening a public issue with exploit details.

## Security and privacy model

License Picker is an offline, dependency-free reference tool. It does not access the network, execute project code, inspect private repositories, collect telemetry, or require credentials. Input is limited to CLI arguments supplied by the user.

The license summaries are informational and are not legal advice. Security reports should concern the software itself rather than disagreements about license interpretation.
