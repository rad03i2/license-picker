# Contributing

Thanks for improving License Picker.

1. Fork the repository and create a focused branch.
2. Keep the runtime dependency-free unless a dependency is clearly justified.
3. When changing license facts, verify them against the official license text and describe the source in the pull request.
4. Add or update tests for behavior changes.
5. Run `python -m compileall -q src` and `pytest -q` before opening a pull request.
6. Keep documentation claims aligned with implemented behavior.

This project provides educational summaries, not legal advice. Contributions must not present recommendations as legal conclusions.
